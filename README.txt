.nojekyll: Serve these files as a static GitHub Pages site.

Rebuild
python build.py

Publish
Upload these files to the root of the public astra-privacy repository.
In Settings > Pages, select Deploy from a branch, main, / (root).
Use the published HTTPS page URL in Google Play Console, not a repository
file preview or a raw source URL. Verify anonymous access before submission.

Policy scope
This policy describes version 1.0.4 with local saves and disabled ads/billing.
Reassess app data handling, third-party providers and retention before
enabling advertising, purchases, online accounts or server-side storage.
Do not place support messages, credentials or game source in this repository.
